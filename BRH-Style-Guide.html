04 — Usage Guidelines
Color Application Rules

Do

  • Use BRH Navy for all headings and primary text
  • Use BRH Coral exclusively for CTAs and key action elements
  • Use Sky Blue as an accent — step numbers, links, icon highlights
  • Pair navy backgrounds with white or sky blue type
  • Use coral tints (50–100) for warm background sections
  • Maintain sufficient contrast — navy on white, white on coral/navy
  • Put icons and number badges inside a circle (border-radius: 50% / rounded-full), never a rounded square

Don't

  • Don't use coral for body text or decorative elements
  • Don't wrap an icon or number badge in a rounded square — icon chips are always circular
  • Don't place sky blue on white without sufficient weight/size
  • Don't use more than 2 primary colors in a single component
  • Don't mix coral and sky blue as competing focal points
  • Don't substitute other fonts for Outfit
  • Don't use font weights below 400 for body text

Coral — Primary CTA

  • "Get Pre-Qualified" / "Apply Now" buttons
  • Key stat callouts and highlights
  • Badge labels and tags
  • Inline emphasis in headlines

Navy — Structure & Authority

  • All H1–H3 headings
  • Navigation bar
  • Footer background
  • Secondary buttons and borders

Sky Blue — Friendliness & Flow

  • Step / process numbers
  • Hyperlinks
  • Icon accents and indicators
  • Decorative UI elements

Neutrals — Supporting Roles

  • Body copy: slate-600 (#4b5563)
  • Card / panel backgrounds: #f0f4f8
  • Off-white page background: #fafafa
  • Dividers and borders: #e5e5e5
